# Gojo 首页空间分区设计

> 日期：2026-08-01  
> 状态：已确认，待实施  
> 范围：只调整首页 `ShelfView` 的信息层级与视觉分区，不改变空间领域模型、领域详情页或拖放语义。

本文档替代 `2026-07-30-gojo-shelf-ui-design.md` 中“公共空间位于轮播首位”的首页布局约定，其余既有设计继续有效。

## 1. 目标

当前首页把公共空间、编码空间和新建入口放在同一条焦点轮播中，两类空间的用途不够容易区分。本次将首页改成上下双排：公共空间作为紧凑状态带，编码空间作为主操作轮播。两排使用不同明度和饱和度，但仍属于现有深色视觉系统。

## 2. 已确认方案

采用“状态带 + 主轮播”布局：

- 上排是公共空间状态带，使用冷灰色调。
- 下排是编码空间主轮播，沿用 Gojo 品牌蓝。
- 公共空间从现有轮播队列移除。
- 编码空间轮播继续包含所有编码空间和末尾的“新建编码空间”卡片。

颜色不是唯一的区分手段。两排还分别使用明确标题、`globe` / `shippingbox.fill` 图标和不同组件形态，保证色觉差异不会影响理解。

## 3. 布局与内容

### 3.1 公共空间状态带

状态带位于品牌字标下方、编码空间轮播上方。它展示：

- 标题“公共空间”和 `globe` 图标。
- 公共项目总数。
- 已克隆项目数。
- 待同步项目数，即 `cloned == false` 的项目数。
- “打开公共空间”操作提示。

整块状态带可点击，点击后沿用现有领域展开动画进入 `.publicSpace`。公共空间尚未指定时，统计区域替换为“尚未指定公共空间”和“点击设置”，点击仍进入公共空间空态页。已指定但没有项目时显示“暂无公共项目”。

### 3.2 编码空间主轮播

下排标题为“编码空间”，继续使用横向焦点轮播。队列调整为：

```text
N 个编码空间 + 新建编码空间
```

现有交互保持不变：

- 滚动或左右方向键改变焦点。
- 点击非焦点卡先居中。
- 再次点击焦点卡进入对应编码空间。
- 点击“新建编码空间”调用现有创建流程。
- 保留焦点卡放大、发光和呼吸动画。
- 开启“减弱动态效果”后继续退化为无位移动画。

没有编码空间时，轮播只显示居中的“新建编码空间”卡片，不增加额外空态组件。

## 4. 视觉规范

公共空间使用现有冷灰语义色：`chrome`、`surface`、`cardStroke` 和中性文本色。编码空间继续使用 `coreBlue` 与 `lightBlue`。本次不引入新品牌色。

公共状态带比编码卡更扁、更宽、层级更轻；编码轮播占据首页主要高度。两排之间保留清晰留白或发丝分隔，使窗口最小尺寸 `720 × 460` 下仍能完整显示。

## 5. 代码边界

- `ShelfView.swift`：负责双排容器、公共空间统计、编码空间轮播焦点与导航。
- `ShelfCard.swift`：继续只负责编码空间卡和新建卡；移除公共空间卡的展示分支。
- `ShelfItem`：只保留 `.coding(URL)` 和 `.newSpace`。
- `AppState` 与 `GojoCore`：不增加状态或修改数据模型。

公共空间统计由 `state.publicProjects` 在视图中派生，不缓存、不写回。领域页、拖放、异步任务和错误处理保持现状。

## 6. 无障碍与键盘

- 公共状态带提供包含当前状态的组合无障碍标签和“打开公共空间”提示。
- 卡片与状态带不只依赖颜色传达类别。
- 保留左右方向键轮播导航。
- 继续读取 `accessibilityReduceMotion`，不新增无法关闭的动画。
- 文本保持单行或有限行数，避免较大字体时与统计内容重叠。

## 7. 错误处理

本次没有新增异步操作或失败路径。进入公共空间、新建编码空间和进入编码空间都继续使用现有 `AppState` 方法及全局错误提示。统计仅反映当前内存状态，不单独报错。

## 8. 验收与测试

自动验证：

- `swift test` 全部通过。
- `swift build` 成功。
- 现有轮播焦点纯逻辑测试继续通过。

手动验收：

1. 首页清楚显示上方公共空间与下方编码空间两排。
2. 公共空间是冷灰状态带，编码空间是品牌蓝轮播。
3. 公共空间未指定、无项目、有已克隆和未克隆项目时摘要正确。
4. 点击公共状态带进入公共空间。
5. 编码空间点击、二次进入、左右键和新建入口行为不变。
6. 窗口处于最小尺寸时布局不遮挡品牌字标、作者署名或分页指示器。
7. 开启“减弱动态效果”后没有呼吸或位移动画。

## 9. 不在范围内

- 不修改公共空间或编码空间领域详情页。
- 不增加空间搜索、排序或自定义封面。
- 不改变拖放、成员模式或存储结构。
- 不新增品牌色或第三方依赖。
