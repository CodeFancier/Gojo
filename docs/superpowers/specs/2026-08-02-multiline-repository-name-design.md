# 编码空间仓库名多行显示设计

## 目标

进入编码空间后，仓库名称不再被强制压缩为单行；常见长名称能够直接完整阅读。

## 布局

- 保留当前 `220–280pt` 自适应卡片宽度。
- 仓库名称从单行中间截断改为自然换行，不限制行数，直到完整显示。
- 名称区域按实际行数增高，卡片随内容增高；网格继续顶部对齐。
- 为名称添加完整文本悬停提示，便于快速查看和复制识别。
- 不预留固定行高，短名称卡片保持紧凑。

## 保持不变

分支名称、来源图标、Agent Memory 入口、悬停操作栏、右键菜单、拖拽、VoiceOver 和 Reduce Motion 行为均不改变。

## 验证

- 使用短名称和需要 4 行以上的长名称检查卡片布局。
- 确认长名称不再使用中间省略号，悬停可读取完整名称。
- 确认 720pt 窗口仍保持三列且无横向裁切。
- 运行构建、完整测试和干净提交树构建。
